Official brand icons (optional)
================================
The site shows its own simple icons for WhatsApp, Gmail, Instagram and Call.
To use the platforms' official icons instead, download them from each company's
brand resources page and save them here as SVG files with exactly these names:

  whatsapp.svg   gmail.svg   instagram.svg   phone.svg
  facebook.svg   youtube.svg linkedin.svg    x.svg

Restart is not needed: reload the website and the official icons appear.
Follow each company's brand guidelines (no changes to colours or shapes).
